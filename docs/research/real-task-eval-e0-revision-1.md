# 真实任务评测 E0 修订 1(判定指标)

> 日期:2026-10-08。依据:[E0 协议 v2](./real-task-eval-e0-protocol.md)。状态:修订草案,待维护者确认。

## 1. 为什么修订,以及它的时间顺序

v2 的主指标是 `fullyServed`(前 5 名必须包含全部可接受 Practice 且无禁项),门槛为成功率点估计 ≥ 85%、Wilson 下界 ≥ 80%。

**本修订是在看到 control 在 380 条独立请求上的面板结果之后提出的。** 结果显示,control 在前 5 名中至少命中一个可接受 Practice 的比例(any-help)约为 47%,fullyServed 约为 41%。维护者认为 fullyServed 标准过严。这是事后调整,不是预先登记的变更。因此:

- 本修订不改变已有的 control 结果,只增加一个报告口径;
- 所有结果都需同时报告 any-help 与 fullyServed,不得只报其中一个;
- 此后若再调整指标或门槛,必须在新数据上预先登记,不能再用这批 380 条判定。

## 2. 新的判定口径

| 指标 | 定义 | 角色 | 门槛 |
| --- | --- | --- | --- |
| any-help | 前 5 名至少包含一个可接受 Practice | **主指标** | 点估计 ≥ 80% |
| fullyServed | 前 5 名包含全部可接受 Practice 且无禁项 | 次要指标 | 点估计 ≥ 60%(本修订提议值,需维护者确认) |
| 禁项率 | 前 5 名含 forbidden 的 query 比例 | 辅助 | 不高于 control 既有水平 |

"可接受 Practice"指经面板两名及以上评审标为 required-core 或 sufficient-alternative 的条目,引文已经脚本核对。

判定:主指标点估计 ≥ 80% 且 fullyServed ≥ 60% 且禁项不增,才算通过;任一未达,不算通过。Wilson 区间照常报告,但不作为本轮判定条件,以免门槛再次被移动。

## 3. 本修订下的 control 结果(仅为记录,不构成新的判定依据)

- 有目标 query:156 / 380(多数票口径)
- any-help:74 / 156 ≈ 47.4%(Wilson 95%:39.8%–55.2%)
- fullyServed:64 / 156 ≈ 41.0%(Wilson 95%:33.6%–48.9%)
- 禁项在前 5 名出现:4 / 380

按本修订,主指标与次要指标均未达标,判定为**未通过**。即使取 any-help 区间上界(55%),也远低于 80%。因此修订不改变结论方向:当前检索在独立真实请求上的前 5 命中远低于目标。

## 4. 已知限制(必须随结果一并报告)

- 面板的"有目标"在三名评审之间有约 19% 的分歧(71 / 380 条)。
- 面板的 A 评审在 pool-2 上未逐行读完整正文,已披露;排除其标签后多数票不变。
- 所有评审为同一家族 agent;人工理由卡抽查尚未完成,结论为参考性。
- 标注候选池来自 control 前 10 名,可能低估 control 未召回的可接受 Practice。
- 只有一位协作者,全部中文,项目分类大量为 `other`。

# Design

## Context

此变更解决规划时遗漏后续检索事项的问题。现有 Skill 和 CLI 已提供按需语义检索、全文读取和失败恢复；不重复规定开发生命周期。

## Goals / Non-Goals

- 目标：保留跨 `init` 回传；把一次检索和消费合并为一个模型工具调用；旧编号在检索前失效。
- 非目标：改写历史或压缩摘要、强制模型查阅或应用、去重无编号检索、新增 `lore check`，或保证进程崩溃后恰好执行一次。

## Decisions

- `scripts/skill-guidance/profiles.ts` 的 Skill 描述承担规划提醒；`scripts/skill-guidance/content/skill.md.tmpl` 的短正文说明按需 query、全文 get、用户授权及不得为 Lorelum 创建或重置计划。通过原生成器生成 portable 与宿主文件。
- 计划只记录后续要解决的问题和时机，不要求写入 Practice 正文或已读指导。宿主能安全更新时使用已有能力；不要求额外的计划编辑操作。Catalog 既有发现路径与精确 ID 直读分开，仍沿用 CLI 的发现、全文读取和恢复合同。
- Skill 描述保持简短，生成的 YAML `description` 必须解析为完整字符串；把 omp 的 `[query: 问题]` / `[get: 精确 ID]` 示例放在正文。`check` 用普通步骤文本，不维护第二套检查状态。不要为迁就提醒新增 todo 参数。
- omp 继续从成功的原生 todo 结果登记：`init` 读提交后的任务，`append` 只读提交的追加项。同一待查动作不重复登记；已关闭的旧标记随 `init` 带回时不恢复，显式 `append` 可以生成新编号。提醒类型与目标一并保存在当前分支，不改原生任务与状态。
- `--todo` 是 omp Bash 工具里独立、直调的 `lore query/get` 命令修饰符。用可核对的命令识别边界提取编号，确认在当前分支待处理且动作和目标匹配，再移除该修饰符、交给原生 Bash 审批和执行；不支持的带编号形态不得当作普通查询放行。普通命令和通用 CLI 功能不变。不另建会话服务，也不绕过宿主审批直接执行命令。
- 以工具调用 ID 关联原分支、提醒和执行结果。用现有 CLI 结构化结果区分非空候选、全文、空结果和准备状态，不能只看退出码。只在取得有效结果且成功写回原分支后报告已处理。一个编号执行中不重复调度，切换分支后不得写入新分支。保存失败要说明提醒未消费；执行到保存前崩溃可能需要重试。
- omp 会裁剪 Bash 返回的长 JSON 行。绑定调用把 CLI 标准输出写入专用临时文件。扩展从完整输出判断是否消费，将结果连同状态放回同一个工具响应，并清理捕获文件。
- 保留终态以识别旧编号；终态项不再回传为待办。未知、终态、动作不匹配的编号在执行前返回明确原因。显式关闭工具只用于用户撤销，不进入成功查阅路径。

## Observed Evidence

- 原生 Skill 对照：omp 18.17.0、`openai/gpt-6.2-sol` medium、Lorelum CLI 0.1.0-alpha.7、临时 Northstar Pack。启用 Skill 的首版 todo 在验收阶段写了查阅 Practice；关闭时没有。两组都在保存初始清单后查询、读取 `northstar.csv.rejection`，并交付第 3 行和 `QTY_FORMAT_INVALID`。
- 单独的 todo 来源探针：用户消息没有查询要求，查询问题仅预置在 todo。一次正常推进中，`todo done` 的结果把新查询事项带进模型请求；模型此后针对物理行号和稳定错误码查询、读取并应用。主动 `todo view` 也可带回同一事项。无事项的对照仍能查询并交付正确结果，故不证明 todo 提高检索或应用率。
- 保留边界与反例：两组已有计划的四次运行均保留原任务和状态，但未补写提醒。另一次预置探针，模型在收到查询事项前调用 `init` 覆盖了原计划。三次 RPC 可见性探针均显示更新已写入、第一条请求未带新任务、后续请求才通过宿主提醒带回。原生测试环境的初期工具配置失败不计作成功。
- omp 19.1.0 的早期 `echo` 探针验证了执行前拦截、命令改写与同一工具响应补充状态。拦截在该版本表现为工具错误。
- 实机使用 Lorelum CLI 查询得到候选并消费 `P1`。真实压缩仍保留 `P1`，显式重放被宿主拦截，重建继续显示 `P2`，随后全文读取消费 `P2`。原生审批拒绝绑定查询后，提醒仍待处理。

## Risks / Trade-offs

回传保住待查原文，但样本未观测到查阅率提升。新交互以工具调用数和实际进入检索的次数验收，不以摘要是否还含旧文字为准。`query` 有候选不等于模型读过或应用了 Practice。

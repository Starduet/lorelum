Lorelum helps your coding agent find relevant engineering guidance while it
works. Complete [Quickstart](./quickstart) first so the `lore` command and at
least one Pack are available to the agent.

## Choose your agent

| Agent | Recommended setup |
| --- | --- |
| Codex | Install the [Lorelum Plugin](./codex). |
| ZCode | Install the [Lorelum Plugin](./zcode). |
| Claude Code | Add the Lorelum Skill to the project or your personal Skills folder. |
| Cursor | Add the Lorelum Skill to the project. |
| Another command-capable agent | Use its supported Skill mechanism or project instructions. |

## Add the Skill

For Claude Code, add the Skill to this project:

```sh
mkdir -p .claude/skills/lorelum
curl -fsSL https://raw.githubusercontent.com/lorelum/lorelum/main/skills/lorelum/SKILL.md \
  -o .claude/skills/lorelum/SKILL.md
```

For personal Claude Code use, put the same file in
`~/.claude/skills/lorelum/SKILL.md`.

For Cursor, add it to the project:

```sh
mkdir -p .cursor/skills/lorelum
curl -fsSL https://raw.githubusercontent.com/lorelum/lorelum/main/skills/lorelum/SKILL.md \
  -o .cursor/skills/lorelum/SKILL.md
```

## First use

Start a new task and tell your agent:

```text
Use Lorelum to find engineering guidance for this task before you finalize the plan.
```

The agent should use the installed guidance when it can help with a design,
implementation, verification, or recovery decision.

## If it does not work

1. Check that `lore --version` works in the environment used by the agent.
2. Check that the Skill or Plugin is installed and enabled.
3. Start a new task after installing or updating a Plugin.
4. Use [Troubleshooting](./troubleshooting) if Lorelum starts but cannot
   retrieve guidance.

## Update

For a file-based Skill, replace `SKILL.md` with the latest version. For Codex
and ZCode, update the Plugin in the host application; their installation pages
explain the exact steps.
